## Завдання № 1. Обчислення суми ряду

### Умова завдання

<img width="642" height="266" alt="task1_condition" src="https://github.com/user-attachments/assets/e5ccba38-7f4c-4eea-a822-d92aba79b4ac" />


Не використовуючи стандартні математичні функції, потрібно обчислити суму ряду:

```math
S = 1 + \sum_{n=1}^{N} (-1)^{n-1}\cdot\frac{a^n}{a+(-1)^{n-1}\,n}
```

Параметр `a` та ціле число `N` вводяться з клавіатури, причому `N ≥ 1`. Якщо знаменник певного доданка дорівнює нулю, цей доданок не враховується в сумі.

**Вихідний код:** [main.c](Task1/main.c) · [funcs.c](Task1/funcs.c) · [funcs.h](Task1/funcs.h) · [проєкт Code::Blocks](Task1/Task1.cbp).

### Введення та перевірка даних

У головній функції `main()` користувач вводить значення `a` та `N`. Перевірка виконується в циклах `while`: якщо введено неправильне значення, з'являється повідомлення про помилку й запит повторюється. Також перевіряється наявність зайвих символів у рядку.

Фрагмент перевірки цілого числа `N` із файлу [Task1/main.c](Task1/main.c):

```c
// Введення N з перевіркою коректності
while (1)
{
    printf("Введіть ціле число N (N >= 1): ");
    readStatus = scanf("%d", &N);
    extra = 0;

    // Перевірка наявності зайвих символів
    while ((ch = getchar()) != '\n' && ch != EOF)
    {
        if (!isspace((unsigned char)ch))
            extra = 1;
    }

    if (readStatus == 1 && !extra && N >= 1)
        break;

    printf("Помилка: некоректне значення N. Спробуйте ще раз.\n");
    if (ch == EOF) return 1;
}
```

**Приклад перевірки введення:** спочатку замість `a` введено текст, потім для `N` введено `0`. Програма дозволяє виправити обидві помилки без перезапуску.

### Обчислення суми ряду

Обчислення винесено в окрему функцію `calculate_series()` у файлі [Task1/funcs.c](Task1/funcs.c). Степінь `a` обчислюється множенням `power *= a`, знак доданка змінюється залежно від парності `n`. Якщо знаменник дорівнює нулю, доданок пропускається, а лічильник `skipped` збільшується.

```c
double calculate_series(double a, int N, int *skipped)
{
    double sum = 1.0;
    double power = 1.0;

    *skipped = 0;

    // Послідовне обчислення доданків ряду
    for (int n = 1; n <= N; n++)
    {
        // Обчислення a^n без використання pow()
        power *= a;

        // Визначення знака (-1)^(n-1)
        int sign = (n % 2 == 1) ? 1 : -1;

        double denominator = a + sign * n;

        // Пропуск доданка з нульовим знаменником
        if (denominator == 0.0)
        {
            (*skipped)++;
            continue;
        }

        sum += sign * power / denominator;
    }

    return sum;
}
```

Для `a = 2`, `N = 4` отримано суму **11.2666666667**. Один доданок пропущено через нульовий знаменник.

### Введення матриці та перевірка даних

Матриця оголошена як `int matrix[MAX_SIZE][MAX_SIZE]`, де `MAX_SIZE = 100`. Користувач вводить розмір `N` у межах від 1 до 100, після чого — кожен елемент матриці. Якщо допущено помилку, програма повторно запитує лише поточний елемент.

Фрагмент із файлу [Task2/main.c](Task2/main.c):

```c
// Зчитування елементів матриці з повторним запитом у разі помилки
printf("\nВведіть елементи матриці:\n");
for (i = 0; i < N; i++)
{
    for (j = 0; j < N; j++)
    {
        while (1)
        {
            printf("A[%d][%d] = ", i, j);
            readStatus = scanf("%d", &matrix[i][j]);
            extra = 0;

            // Перевірка коректності введеного елемента
            while ((ch = getchar()) != '\n' && ch != EOF)
            {
                if (!isspace((unsigned char)ch))
                    extra = 1;
            }

            if (readStatus == 1 && !extra)
                break;

            printf("Помилка: некоректний елемент. Спробуйте ще раз.\n");
            if (ch == EOF) return 1;
        }
    }
}
```

**Приклад перевірки введення:** при неправильному розмірі (`0` або літери) та неправильному значенні елемента матриці запит повторюється.

### Пошук максимального елемента

Функція `find_max_lower_triangle()` у файлі [Task2/funcs.c](Task2/funcs.c) проходить по рядках матриці. Умова `j <= i` обмежує перегляд головною діагоналлю та елементами нижче неї. Під час пошуку запам'ятовуються максимальне значення та його індекси.

```c
int find_max_lower_triangle(int matrix[][MAX_SIZE], int N,
                            int *max_row, int *max_col)
{
    int max_value = matrix[0][0];
    int i, j;

    // Ініціалізація індексів першого допустимого елемента
    *max_row = 0;
    *max_col = 0;

    // Перегляд головної діагоналі та елементів під нею
    for (i = 0; i < N; i++)
    {
        for (j = 0; j <= i; j++)
        {
            // Оновлення максимуму та його координат
            if (matrix[i][j] > max_value)
            {
                max_value = matrix[i][j];
                *max_row = i;
                *max_col = j;
            }
        }
    }

    return max_value;
}
```
